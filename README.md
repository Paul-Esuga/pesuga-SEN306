# SEN306 Software Construction Repository

## 📌 Overview

This repository contains coursework, projects, and practical implementations for **SEN306 – Software Construction** at Pan-Atlantic University.

The goal of this course is to develop strong software development practices, including clean coding, version control, testing, and system design.

---

## 🚀 Features

* Implementation of core software construction concepts
* Object-Oriented Programming (OOP) projects
* Version control using Git and GitHub
* Practical assignments and mini-projects
* Code structured using best practices

---

## 🛠️ Technologies Used

* Java
* Git & GitHub
* (Optional) Python / JavaScript for supporting tasks
* IDEs: NetBeans / VS Code

---

## 📂 Project Structure

```
/src        → Source code files  
/docs       → Documentation (if any)  
/tests      → Test cases (if applicable)  
```

## 📚 Learning Objectives

* Understand software construction principles
* Write clean, maintainable code
